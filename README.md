# ⚔ Scalyx SMP Official Website ⚔

The official Minecraft-themed React web application for **Scalyx SMP** (`smp.scalyx.in`).

## 🎮 Server Details
- **Server IP:** `smp.scalyx.in`
- **Edition:** Minecraft Java Edition 1.21.4
- **Gameplay:** High-Stakes Semi-Anarchy (KeepInventory permanently OFF for all ranks)

---

## 🚀 Running the Website

### Development Mode:
```bash
npm run dev
```
Runs the Vite development server with Hot Module Replacement on `http://localhost:3000`.

### Production Build & Preview:
```bash
npm run build
npm run preview
# or simply execute:
./start-website.sh
```

## 🗺 Pages & Features
1. **Overview / Home (`/`)**:
   - Hero banner with Server IP copy button and confetti effect
   - Core server pillars (Semi-Anarchy, Lifestealer Relic, Custom Worlds, Scam-Proof Economy)
   - Interactive preview of the Lifestealer 3x3 crafting altar
   - Quick Join Guide for Java 1.21.4 players
2. **Survival & Mechanics**:
   - Explicit confirmation of **KeepInventory: OFF** for all ranks
   - 6-Row portable Ender Chest (`/ec` - 54 slots)
   - Graphical Home Manager (`/homes` - 15 waypoints)
   - Safe Wilderness Random Teleport (`/rtp` - 15,000 blocks)
   - Portable Incinerator (`/trash`) & Real-time Skin Wardrobe (`/skin`)
3. **Mythic Combat & Weapons**:
   - **The Lifestealer Relic**: Server-wide limit of 1, Dragon Egg recipe, 30-minute global coordinate broadcast siren, Soulbound mechanics, Vitality Theft, Wither Decay, and Heart Siphon Nova.
   - **The 4 Mythic Rank Blades**: Independent cooldowns, 5s charged ultimates, 10% on-hit passives, and wielder immunities (Sculk Annihilator, Eternal Zenith Blade, Wither Reaper Blade, Void Sovereign World-Ender).
   - **DonutSMP 3x3x1 Super Pickaxes**: Toggleable quarry mode vs 1x1 precision mode.
4. **Custom World & Generation**:
   - Terralith 2.5 (Overworld 85+ biomes)
   - Incendium (Nether infernal sanctums)
   - Nullscape & Stellarity (End dimension overhaul and revamped Ender Dragon multi-phase fight)
   - Dungeons and Taverns, Explorify, Structory procedural castles and keeps
5. **Economy & Trading**:
   - DonutAuctionHouse (`/ah`)
   - Official Categorized Merchant Shop (`/shop`)
   - Scam-Proof Dual-Lock Trading System (`/trade`)
6. **Ranks & Kit Progression**:
   - 8 Rank Tiers: Coal, Iron, Gold, Blaze, Warden, Eternal, Wither, Ender
   - Downward Kit Claim Guarantee: Higher ranks claim all subordinate kits
   - Dynamic Max Health Scaling: Full armor sets increase HP up to 20 hearts (40 HP)
